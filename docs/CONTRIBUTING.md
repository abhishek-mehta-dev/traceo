# Contributing

Contributions to Traceo are welcome.

## Getting Started
- Review the README and PRD to understand the project direction.
- Open an issue for bugs, features, or documentation improvements.
- For larger changes, discuss the approach before implementation.

## Development Workflow
1. Create a feature branch from main.
2. Make focused changes with clear commit messages.
3. Open a pull request for review.

## Code of Conduct
Please be respectful and constructive in all interactions.
